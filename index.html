Ajustes

Sin clave, la app funciona en modo demo con un catálogo de ejemplo. Con clave accedes a más de 90 países y cientos de plataformas, con datos reales. Es gratis:

  1. Crea una cuenta en themoviedb.org.
  2. Entra en Ajustes → API y solicita una clave de uso personal.
  3. Copia la API Key (v3 auth) y pégala arriba.

La clave se guarda solo en este navegador. Si algún día publicas la web, ten en cuenta que sería visible en el código; para eso haría falta un pequeño servidor intermedio.
